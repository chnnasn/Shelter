# Shelter

一款使用 Unity 开发的 2D 生存策略游戏。玩家需要在风暴到来前派遣居民收集资源、建设防御设施，并在逐渐增强的生存压力下维持避难所运转。

## 游戏玩法

- 在倒计时结束前规划居民与资源分配
- 派遣居民外出探索，消耗食物并带回木材、石材和新居民
- 在网格地图上建造食物与防御设施
- 应对周期性风暴以及不断提高的资源需求
- 根据人口、食物和防御储备决定生存结果

## 技术栈

- Unity `2021.3.18f1c1`
- C#
- UGUI
- QFramework
- Unity 2D、Tilemap 与 Particle System

## 核心系统

### 网格建造系统

`Grid` 使用队列遍历生成二维建造网格，并通过坐标转换将世界坐标映射为网格坐标。系统使用字典记录格子占用状态，处理建筑选择、资源消耗和实例化，避免在已占用位置重复建造。

### 资源与人口循环

`GameManager` 统一维护食物、木材、石材、人口和防御值。居民派遣会消耗食物，并在探索结束后结算资源、人员损耗和新增人口，形成探索、建设和生存之间的资源循环。

### 时间与风暴系统

`CountDown` 将游戏时间转换为天、小时和分钟，并按天扣除人口所需食物。阶段倒计时结束后触发风暴，通过粒子系统表现天气变化，再根据当前资源与防御值进行阶段结算。

### 难度递进与结算

风暴会在特定天数触发，并逐步提高食物、防御和建筑需求。结算系统根据玩家储备判断是否成功抵御风暴，同时处理建筑损失、失败状态和最终通关结果。

### 数据模型

项目基于 QFramework 注册关卡、建筑、物品和探索数据模型，将部分玩法数据与场景逻辑分离，为关卡扩展和数值调整提供统一入口。

## 项目结构

```text
Assets/
├── Scenes/                 Unity 场景
├── Scripts/
│   ├── Controller/        控制器基类
│   ├── Models/            关卡、建筑、物品与探索数据
│   ├── GameManager.cs     核心状态与风暴结算
│   ├── Grid.cs            网格生成与建筑放置
│   ├── GridManager.cs     输入与网格交互
│   ├── CountDown.cs       时间推进与阶段触发
│   └── Maker.cs           建筑生产逻辑
├── QFramework/            项目架构依赖
└── Tiles/                 2D 地图资源
```

## 运行项目

1. 安装 Unity Hub。
2. 使用 Unity `2021.3.18f1c1` 打开仓库目录。
3. 等待 Package Manager 完成依赖导入。
4. 在 `Assets/Scenes` 中打开游戏场景并进入 Play Mode。
